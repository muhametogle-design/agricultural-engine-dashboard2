You are an expert Frontend and Full-Stack Developer specializing in modern React, Tailwind CSS, Lucide icons, and advanced dashboard UX design.

Build a comprehensive, production-ready Laboratory Information Management System (LIMS) dashboard for an agricultural soil testing facility. Incorporate the following distinct modules, financial structures, specific calculation engines, and interactive plant pathology widgets seamlessly into a single-page interactive application using robust local React state.

### DEPLOYMENT & ASSET RULES (strict — override everything else)
1. SINGLE-PAGE, SINGLE-ORIGIN DELIVERY: The entire LIMS must load and run from the same page and the same HTTP origin as the main software (one self-contained HTML file served at `/lims` inside the existing app — e.g. http://localhost:8000/lims). No separate website, no external rundown.
2. OFFLINE-SAFE ASSETS — NO EXTERNAL CDN DEPENDENCIES: do NOT rely on runtime internet hosting (unpkg / jsdelivr / cdn.tailwindcss) for React, Recharts, Lucide or Tailwind. Either (a) embed/vendor all required libraries inside the app package so every asset is served same-origin (e.g. /web/vendor/react.min.js), or (b) compile React/Recharts components into a single dependency-free bundle inlined in the HTML. The page must render fully functional even with the internet cable unplugged. Add a tiny console self-check so a missing library shows a visible error box instead of a blank page.
3. COMPILER SAFETY: if an in-browser JSX transformer is used, restrict JS syntax to what that compiler supports — avoid `??`, `?.`, and any ES2020+ operator; declare the Babel presets explicitly (es2015, es2016, react, stage-2). Prefer no-JSX `React.createElement` or a build-free approach so the page never fails on syntax.

### PAYMENT ENGINE OVERRIDES (strict)
4. FLEXIBLE AMOUNT INPUT, NOT FIXED TIERS: The "Receive New Payment" form must include a free numeric "Amount Paid (USD)" field where staff can type exactly what the farmer paid — not restricted to fixed tier prices. ### MODULE 6: INTERACTIVE HIERARCHICAL PLANT PATHOLOGY & DIAGNOSTIC WIDGET
Design a dedicated interactive dashboard block named "Agronomic Disease & Treatment Intelligence System" operating on a step-by-step layout:

Data tree (embed verbatim):
1. Apple Tree
   - Fire Blight | Erwinia amylovora (Bacterium) | Prune infected limbs 8–12 inches below damage using tools sanitized with 10% bleach/isopropyl alcohol. Apply copper-based bactericides during early spring bloom.
   - Apple Scab | Venturia inaequalis (Fungus) | Rake and burn fallen autumn leaves to eliminate overwintering spores. Spray with preventative fungicides (captan or flutriafol) starting at the green-tip growth stage.
2. Peach Tree
   - Brown Rot | Monilinia fructicola (Fungus) | Remove and destroy all mummified fallen fruit on orchard floors. Apply preventative fungicides (sulfur or propiconazole) from early bloom through harvest.
   - Peach Leaf Curl | Taphrina deformans (Fungus) | Apply a single lime-sulfur or copper-based fungicide spray during winter dormancy before buds swell in spring.
3. Wheat & Coffee Crops
   - Rust Disease | Puccinia spp. / Hemileia vastatrix (Fungus) | Plant resistant crop cultivars. Spray with triazole or strobilurin-class chemical fungicides immediately at the first sign of pustules.
   - Damping-Off | Pythium / Rhizoctonia (Soil Fungi) | Avoid overwatering; ensure optimal field drainage. Use fungicide-treated seeds and avoid planting into cold, waterlogged soils.
4. Tomato & Potato Vegetables
   - Early Blight | Alternaria solani (Fungus) | Prune lower leaves to maximize airflow and stop splash-transmission. Avoid overhead sprinkler irrigation. Apply chlorothalonil preventatively.
   - Late Blight | Phytophthora infestans (Water Mold) | Completely destroy and burn infected plants (do not compost). Apply targeted oomycete fungicides (metalaxyl or copper sulfate) during periods of high humidity.

Interaction workflow:
- Step 1 — Plant Selection: clean grid of clickable category cards (Apple Tree, Peach Tree, Wheat & Coffee Crops, Tomato & Potato Vegetables).
- Step 2 — clicking a plant immediately opens a dynamic sub-list showing ONLY that plant's diseases.
- Step 3 — clicking a disease populates an immediate "Actionable Treatment Plan" frame listing: Biological Root Cause (isolated pathogen strain), Immediate Eradication Steps (bulleted), Chemical/Cultural Treatment (exact classes/remedies).
- Farmer Issue Logger mock form: Farmer Name + affected crop + diagnosed disease + button "Log Field Issue & Issue Treatment Sheet". Submitting creates an entry in an on-screen running Issue History feed.
